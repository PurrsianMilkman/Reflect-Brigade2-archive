README for Reflect - A path traced game based on the
Brigade 2 engine. Brigade and Brigade 2 have been
developed at the IGAD program of the NHTV University
of Applied Sciences in Breda, by Jacco Bikker and
Jeroen van Schijndel.

Double-click RUNGAME.bat to run the game.

Reflect was originally developed using Brigade 1,
and ported to Brigade 2 by Jeroen van Schijndel.

Brigade uses all your NVidia GPUs to render frames.
A fast GPU is required to decent quality. The game
will adjust quality to maintain a minimum frame rate.

This package contains a playable version of the game,
as well as its source code, and libraries and
headers for Brigade 2, which you may use in your
own projects.

The game itself is loosely based on Portal 2 by
Valve. Find your way through rooms and corridors,
solving puzzles and staying alive. Controls are:

ASDW: strafe
Mouse: look around
Mouse button 1: pick up objects.

If you are just looking around to play with the
path tracer, you may want to use the debug keys:
'1': Skip room 1 and 2
J, K, L: change materials on glass tube maze.

The project can be rebuild from the included files 
using Microsoft Visual Studio 2008. Reflect uses
the Bullet engine for physcis, and FMod for sound.
